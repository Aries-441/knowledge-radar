# ADR-0002：副作用由确定性程序控制

- 状态：Proposed
- 日期：2026-09-04

## 背景

文章正文属于不可信输入，可能包含针对 Agent 的提示词注入。如果模型同时拥有浏览器、Shell、飞书和知识库写入权限，恶意页面可能诱导它读取凭据、访问其他地址、覆盖文件或发送消息。

本项目的大多数动作都有明确规则，不需要模型自主决定：下载指定 URL、生成归档路径、写入 Markdown、发送给原会话。

## 决定

模型只负责文本理解、摘要、排序和对话。下列副作用全部由普通程序完成：

- URL 验证、下载和重定向
- 浏览器 Profile 选择
- 文件名、Front Matter 和归档写入
- 飞书消息发送
- 任务状态和重试
- Git 和博客发布

模型输出必须转换为内部结构并通过校验，不能直接作为路径、命令或凭据使用。

## 结果

好处：

- 提示词注入的影响范围显著缩小。
- 任务行为更容易测试、重试和审计。
- 更换模型不会改变外部副作用语义。

代价：

- 需要为每种外部动作编写明确适配器。
- 少数动态页面可能需要更多确定性提取逻辑。
- 它不是一个可以随意操作网页的通用 Agent。

## 重新评估条件

只有出现无法通过受限接口表达的真实需求时，才考虑给 Agent 增加自定义工具。新增工具必须限定参数、域名和权限，不能直接开放通用 Shell 或浏览器控制。
